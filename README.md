# YouTube 分析レポート（デモ版）と GAS のコードの作成例

動画ごとの数値の推移、検索キーワード、視聴者を、**毎朝、昨日までの数字がそろうレポート**にする仕組みのデモです。
取れるデータ、条件つきのデータ、取れないデータを、レポートの画面の上で「取れる」「条件つき」「取れない」の印で示します。

- デモ：https://youtube-report-demo.vercel.app
- GAS のコードの作成例：[`gas/`](gas/)（説明は [gas/README.md](gas/README.md)）

> 数値はすべて架空です。本物の YouTube には接続していません。チャンネル「ゆるっと台所チャンネル（架空）」と動画はすべて架空です。
> 納品は Looker Studio で、この画面と同じ構成で作る想定です。

## デモの画面

| 画面 | 内容 |
|---|---|
| チャンネルの概要（`/`） | 指標のカード、日次と週次の推移（直近の3日は「確定前」）、伸びている動画の上位5本 |
| 動画の比較と推移（`/videos`） | 一覧の並べ替え、3本までの比較（日付でそろえる／公開日からの日数でそろえる、日ごと／累計） |
| 検索キーワード（`/search`） | チャンネル全体と動画ごとの上位25件、「上位25件に入らない検索」（合計との差） |
| 視聴者（`/audience`） | 国、年齢と性別（条件つき）、市区町村（条件つき）、都道府県（取れない） |
| このデモについて（`/about`） | 取れるもの一覧、構成図、2段階の納品、許可の進め方、維持費、テストの結果 |

架空のデータは [`src/lib/fakeData.ts`](src/lib/fakeData.ts) で、シード付きの乱数から作ります（いつ開いても同じ数値）。

## 技術

Next.js（App Router）、TypeScript、Tailwind CSS、Recharts。サーバーとデータベースは使いません。

## テスト

```bash
npm ci
npx vitest run          # デモのデータと集計、GAS の作成例の単体テスト
npx next build && npx playwright test   # 通しのテスト（パソコンとスマートフォン）
```

## 写真

料理の写真は [ぱくたそ](https://www.pakutaso.com/) のフリー素材です。再配布が禁止されているため、写真のファイル（`public/photos/`）はこのリポジトリに含めていません。手元で動かすときは、写真が表示されません。
